# Catalog review

Reviewed 2026-10-16 using official project documentation available through GitHub. Product sites blocked by cloud egress were not marked verified. Verification means the conservative description is supported by the source, not a guarantee of service uptime, pricing, platform compatibility for every device, or endorsement. No pricing or integrations were inferred.

40 entries: 30 verified/active, 8 pending, 2 archived. Pending and archived entries are excluded from recommendation candidates. The initial verified set leans toward desktop and open-source tools because their authoritative documentation was accessible.

The broad use-case tags are editorial matching hints, not feature claims; e.g. a writing model is not represented as an Excel integration. Advanced installers are excluded unless technical experience is explicitly mentioned. Known installation limitations are visible on every card; unknown device suitability remains a limitation.
